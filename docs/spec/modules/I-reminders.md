# 模块 I · 提醒

| 元素 | 内容 |
|---|---|
| 文档状态 | 草案 |
| 所属闭环 | L1 执行保障 |
| 上游依赖 | C 计划（FR-I1）、A 档案（FR-I2）、D 记录（FR-I3） |
| 下游被依赖 | 无 |
| 覆盖需求 | FR-I1 ~ FR-I3 |
| 数据表 | 提醒配置随 `transfer_plans` / 用户设置存储；订阅消息授权状态本地记录 |

## 1. 模块定位

计划再好，忘记执行就归零。提醒是 L1 闭环的执行保障。**设计前提（平台约束）**：微信小程序订阅消息为"一次授权、一条一次性消息"，长期订阅需特定类目资质（不依赖）。因此提醒体系以**应用内提醒为主、订阅消息为增强**，任何提醒能力都不因用户拒绝授权而失效。

## 2. 需求明细

### FR-I1 计划节点提醒 `P1`｜依赖：C1/C4｜闭环：L1
- 描述：比例切换日/新增新奶顿次的当日，应用内显著提示 + 引导订阅当条消息（用户点"提醒我"才授权发送）。
- 验收标准：
  - [ ] 未授权时应用内提醒仍可达；
  - [ ] 授权引导不阻断主流程（可关闭，不重复骚扰）。

### FR-I2 喂奶提醒（可选） `P2`｜依赖：A1｜闭环：L1
- 描述：按用户设定的间隔提醒喂奶，可随时关闭。默认关闭，避免打扰。
- 验收标准：
  - [ ] 关闭后不再产生任何推送；
  - [ ] 与记录联动（记录后顺延下次提醒时间，M3 评估）。

### FR-I3 漏记提醒 `P2`｜依赖：D1｜闭环：L2
- 描述：当日零记录且已开启提醒的用户，晚间温和提示一次。
- 验收标准：
  - [ ] 每日至多一次；
  - [ ] 不与红色预警文案混用（预警走 FR-E2 通道，且红色预警优先级更高）。

## 3. 平台能力与降级矩阵

| 能力 | 通道 | 拒绝授权时的降级 |
|---|---|---|
| 比例切换日提醒 | 应用内横幅 + 可选订阅消息 | 应用内横幅（打开小程序可见） |
| 喂奶间隔提醒 | 应用内（使用中） | 无推送，仅打开时提示 |
| 漏记提醒 | 应用内 + 可选订阅消息 | 应用内 |
