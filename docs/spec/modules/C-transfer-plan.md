# 模块 C · 转奶计划引擎（核心差异化）

| 元素 | 内容 |
|---|---|
| 文档状态 | 草案 |
| 所属闭环 | **L1 主闭环的发动机**（解决 Q1「怎么转奶」） |
| 上游依赖 | A 宝宝档案（FR-A1）、B 奶粉库（FR-B1，未收录时可手动输入） |
| 下游被依赖 | D 记录（FR-D5）、E 观察（FR-E2/C5）、F 复盘（FR-F2）、I 提醒（FR-I1） |

| 数据表 | `transfer_plans`、`plan_templates`（见 [03-data-model.md](../03-data-model.md)） |

## 1. 模块定位

把专业转奶方法论（混合法/隔顿法、逐日节奏、禁忌、回退）产品化为"每日可跟随的计划"。用户不需要懂方法论，只需要在创建时回答 4 个问题，之后每天照任务卡执行。这是产品与"记账本"的本质区别，也是北极星指标（计划完成数）的来源。

## 2. 需求明细

### FR-C1 计划创建向导 `P0`｜依赖：A1、B1｜闭环：L1
- 描述：四步向导——①选当前奶粉 ②选目标奶粉 ③选转奶原因（换段位/换品牌/遵医嘱转回/其他）④确认方法与开始日，生成逐日计划。
- 验收标准：
  - [ ] 目标奶粉支持从库选择或手动输入品牌（手动输入时蛋白类型需用户确认，默认"整蛋白"）；
  - [ ] 原因选择影响默认方法（同品牌换段位→混合法；跨品牌/涉及水解配方→隔顿法），用户可改；
  - [ ] 生成前展示计划总览（天数、每日比例/顿数），确认后生效；
  - [ ] 历史完成的计划可"复制为新计划"（预填全部选项）；
  - [ ] 存在历史计划时，向导首页展示上一次转奶摘要（方法、天数、预警与回退次数，数据来自 FR-F2），让复盘经验反哺下一次决策。

### FR-C2 方法模板库（可配置） `P0`｜依赖：无｜闭环：L1
- 描述：转奶方法以模板数据（而非硬编码）实现，运营可调整默认节奏。默认模板：
  - **混合法（7 天）**：同瓶混冲，新奶占比 D1–3：1/3 → D4–6：1/2 → D7：全量。适合同品牌换段位、整蛋白之间；
  - **隔顿法（7–14 天）**：每 2–3 天新增 1 顿新奶，直至全部替换。适合跨品牌、涉及水解配方。
  - ⚠️ 模板默认值上线前须经儿科/营养专业顾问审核（NFR-1），审核记录留档。
- 验收标准：
  - [ ] 模板存储于 `plan_templates` 表，客户端拉取而非内置硬编码；
  - [ ] 模板带版本号，进行中计划锁定创建时版本（避免中途改模板导致进度错乱）。

### FR-C3 逐日任务卡 `P0`｜依赖：C1/C2｜闭环：L1
- 描述：首页与计划页展示"今天"任务：转奶第 N 天、当日新奶比例或顿数、剩余天数；完成当日全部打卡后任务卡标记完成。
- 验收标准：
  - [ ] 跨零点自动滚动到新一天；
  - [ ] 暂停/回退状态下任务卡切换为对应指引；
  - [ ] 无进行中计划时展示"发起新计划"入口（空状态引导）。

### FR-C4 计划状态机 `P0`｜依赖：C1｜闭环：L1
- 描述：`active（进行中）→ paused（暂停，用户主动）→ active`；`active → rollback（回退中）→ active`；`active/paused/rollback → completed（完成）/ terminated（终止）`。状态变更记录时间与原因。
- **完成判定（北极星口径，定义见 00-glossary §3）**：自动——最后计划日的下一喂养日切点，若最后计划日存在 ≥ 1 条喂养记录，计划自动置为 `completed`；手动——`active/paused` 状态下用户可标记完成（二次确认，留痕）。两种均计入北极星；`terminated` 必须选择原因。
- 验收标准：
  - [ ] 非法状态迁移被拒绝（如 completed → active，只能新建计划）；
  - [ ] 同一宝宝同时只允许一个非终态计划（数据库部分唯一索引强制）；
  - [ ] 状态变更在计划时间轴留痕。

### FR-C5 回退方案 `P0`｜依赖：C4、E2｜闭环：L1
- 描述：用户主动或被黄色预警建议时，一键回退到上一稳定比例（或减少一顿新奶），进入 `rollback` 状态，默认观察 3 天后再继续。
- 验收标准：
  - [ ] 回退后任务卡、提醒、记录联动全部按回退后节奏执行；
  - [ ] 回退操作与原因在时间轴留痕；
  - [ ] 回退入口在计划页与黄色预警详情均可触达。

### FR-C6 安全规则拦截 `P0`｜依赖：C1｜闭环：L1
- 描述：创建计划与逐日执行中内嵌安全规则（规则文案可配置，上线前经专业顾问审核，NFR-1）：
  - 创建时：提示"宝宝腹泻/感冒/接种疫苗前后一周内不建议开始转奶"，需用户确认后方可继续；
  - 涉及水解配方 ↔ 普通配方：强提示"请在医生指导下进行，本计划为记录工具"；
  - 宝宝月龄 < 6 个月且原因非医嘱：提示频繁换奶风险，二次确认。
- 验收标准：
  - [ ] 每条规则的确认动作留痕；
  - [ ] 文案不得含诊断/疗效表述（NFR-1）；
  - [ ] 涉及水解配方的强提示不可跳过。

### FR-C7 计划时间轴 `P1`｜依赖：C1/C4｜闭环：L1/L2
- 描述：计划详情页以时间轴展示：每日比例/顿数、实际打卡情况、回退/暂停/完成事件。
- 验收标准：
  - [ ] 计划日与实际记录可对上（当日记奶数、计划内/外顿数）；
  - [ ] 完成的计划可查看历史且可"复制为新计划"。

## 3. 纯函数与测试要求（NFR-5）

- `utils/plan.ts`：`buildPlanDays(template, startDate)` 生成逐日序列、`rollbackTo(plan, day)` 计算回退后序列——必须纯函数 + 单测（边界：模板缺失、开始日为过去、跨月）。
