## 1. 模块定位

一切记录与计划的最小归属单位。产品数据从"用户维度"细化为"宝宝维度"，直接支撑二胎家庭（P2 画像）与月龄驱动的智能提示；体重是转奶适应判断的硬指标（转奶期间体重走势异常是就医信号之一）。

隐私约束（NFR-2）：仅收集昵称（可自定义，不要求真实姓名）、出生日期、性别；**不收集宝宝照片**；建档前须展示隐私政策并取得单独同意。

## 2. 需求明细

### FR-A1 创建/编辑宝宝档案 `P0`｜依赖：H0｜闭环：L1
- 描述：记录昵称、出生日期、性别。首次使用引导创建；不收集宝宝照片。
- 验收标准：
  - [ ] 未创建档案时，记录/计划功能引导至建档页；
  - [ ] 出生日期用于计算月龄，在档案页与计划向导中展示（如"7 月 12 天"）；
  - [ ] 字段均可编辑；月龄计算跨月/跨年正确（纯函数 + 单测）。

### FR-A2 多宝宝切换 `P1`｜依赖：A1｜闭环：L1
- 描述：支持 ≥2 个宝宝，全局切换"当前宝宝"，所有记录/计划/统计按宝宝隔离。
- 验收标准：
  - [ ] 切换后记录列表、计划、统计全部切换且无串数据；
  - [ ] 删除宝宝有二次确认并明示数据将删除。

### FR-A3 体重记录 `P1`｜依赖：A1｜闭环：L2
- 描述：手动记录体重（g/kg），转奶期间建议每周一次；供奶量参考（FR-F3）与复盘（FR-F2）使用。
- 验收标准：
  - [ ] 记录与修改留痕（可查看历史）；
  - [ ] 体重用于 FR-F3 参考量计算；
  - [ ] 无体重时 FR-F3 按月龄档位降级估算而非报错（见 FR-F3 与 00-glossary §1 纯奶期/辅食期）。

### FR-A4 段位转换时机提示 `P1`（M2）｜依赖：A1、C1｜闭环：L1（入口触发）
- 描述：宝宝月龄临近换段节点（6 / 12 / 36 月龄，提前 2 周起），在首页与记录页展示一次性提示条："宝宝快 X 个月了，可以开始规划换 N 段"，点击进入计划向导并预填目标段位（奶粉库按段位预过滤）。段位与月龄对应关系见 00-glossary §1。
- 验收标准：
  - [ ] 仅在无进行中计划时提示；
  - [ ] 点击后进入计划向导且目标段位已预填；
  - [ ] 用户关闭后 7 个喂养日内不再出现；
  - [ ] 提示曝光与点击计入埋点（FR-H4）。
