# 模块 B · 奶粉库

| 元素 | 内容 |
|---|---|
| 文档状态 | 草案 |
| 所属闭环 | L3 数据底座（解决 Q3「怎么选奶粉」） |
| 上游依赖 | 无（运营侧数据） |
| 下游被依赖 | C 计划（选择奶粉）、D 记录（配方结构化）、G 内容（互链） |
| 覆盖需求 | FR-B1 ~ FR-B4 |
| 数据表 | `milk_products`（见 [03-data-model.md](../03-data-model.md)） |

## 1. 模块定位

把奶粉从"文章里的自由文本"变成结构化数据。**`protein_type`（蛋白类型）是全产品的关键字段**——它驱动转奶方法选择（FR-C1）、安全提示强度（FR-C6）与问卷结果（FR-G3）。

中立性约束（产品原则 4 / NFR-1）：数据中性呈现，无推荐语、无排名、无"更好"表述；品牌排序按名称，不按合作或佣金。

## 2. 需求明细

### FR-B1 奶粉数据规范与首批导入 `P0`｜依赖：无｜闭环：L3
- 描述：运营维护的结构化奶粉库。字段规范：
  - 标识：品牌、产品名、段位（1/2/3/4）、版本（国行/海外）、注册号（国食注字 YP / TY，可为空并标注"海外版无国行注册号"）；
  - 类型：蛋白类型（整蛋白/部分水解/深度水解/氨基酸）——**驱动转奶方法与安全提示的关键字段**；
  - 成分：OPO、乳铁蛋白、益生菌、DHA/ARA（布尔或含量）、是否含蔗糖/香精；
  - 使用：冲调比例（按罐体标注）、参考价（区间，非实时）。
- 验收标准：
  - [ ] 首批覆盖国内主流品牌各段位 ≥ 50 个 SKU；
  - [ ] 每条数据有运营侧更新时间与状态（上架/下架）；
  - [ ] 客户端只读，中性口径呈现，无推荐语、无排名。

### FR-B2 搜索与筛选 `P1`｜依赖：B1｜闭环：L3
- 描述：按品牌名搜索；按段位、蛋白类型筛选。月龄可自动过滤不适用段位（可解除）。
- 验收标准：
  - [ ] 搜索支持品牌名与产品名模糊匹配；
  - [ ] 结果为空时给出"未收录，可手动输入品牌继续创建计划"的兜底路径（见 FR-C1）。

### FR-B3 奶粉对比 `P2`｜依赖：B1/B2｜闭环：L3
- 描述：勾选 2–3 款，按成分字段并排对比，差异项高亮；不给出"谁更好"的结论。
- 验收标准：
  - [ ] 对比页固定展示免责声明"信息仅供参考，请以罐体标注为准"；
  - [ ] 数据缺失项显示"暂无"而非留白。

### FR-B4 条码扫描录入 `P3`｜依赖：B1｜闭环：L3
- 描述：微信扫一扫条码匹配奶粉库；未命中时允许提交条码+照片供运营补录。仅记录意图，不在本版本承诺。

## 3. 运营流程要求

- 数据录入走管理后台（apps/admin，模块 J / FR-J2：含 CSV 批量导入），字段填写规范单列 checklist（单位、空值约定）；
- 特医配方（TY 注册号）条目由管理后台自动追加"须在医生指导下使用"标记，供 FR-C6 强提示读取。
