| 元素 | 内容 |

## 1. 模块定位

内容不为"流量"，为"决策"：每一篇内容都应对齐三大问题之一，并与产品功能互链（看到问题 → 有工具接住）。合规是本模块红线（NFR-1）：母乳代用品宣传受《广告法》严格限制，不点名评价品牌、不用绝对化用语、特医奶粉相关内容必须强调就医。

## 2. 需求明细

### FR-G1 知识分类重构 `P1`｜依赖：无（复用现有 articles/favorites 表）｜闭环：L3
- 描述：分类对齐三大问题：怎么转奶（方法/禁忌/回退）、怎么记录（观察要点）、怎么选奶粉（成分科普/段位/避坑）；文章可与奶粉库条目、计划向导互链（"正在转奶？查看对应指南"）。
- 验收标准：
  - [ ] 现有文章列表/详情/收藏（favorites 表已建，页面未接入）全部可用；
  - [ ] 文章发布前有合规审查流程（`review_status` 字段，仅"已审核"内容对客户端可见）。

### FR-G2 避坑与合规专栏 `P1`｜依赖：G1｜闭环：L3
- 描述：固定栏目：配方注册号科普（国食注字 YP/TY，防范固体饮料冒充特医奶粉）、海淘版本差异、转奶常见误区。
- 验收标准：
  - [ ] 内容经专业顾问与法务口径审核后上线；
  - [ ] 不点名评价具体品牌优劣。

### FR-G3 选奶问卷 `P2`｜依赖：B1、A1｜闭环：L3/L4
- 描述：月龄 + 过敏家族史 + 当前症状（便秘/腹泻/湿疹）+ 现用配方 → 输出**配方类型方向**（如"可重点了解部分水解配方，就诊时与医生确认"）+ 对应科普 + 奶粉库筛选入口。**不输出具体品牌排名**。
- 验收标准：
  - [ ] 结果页固定展示"不构成医疗建议"免责声明；
  - [ ] 涉及过敏高风险答案时引导就医优先；
  - [ ] 记录问卷结果用于 L3 采纳率统计（用户是否按方向筛选/创建计划）。

## 3. 运营流程要求

- 内容发布流程：管理后台撰写/编辑（FR-J3）→ 顾问审核（医学正确性）→ 法务口径检查（广告法）→ `review_status=approved` → 可见；
- 采纳率统计口径：问卷完成 → 7 日内创建计划 / 筛选奶粉库的比例。
